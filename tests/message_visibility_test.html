Message Visibility Test - KMune

Messages should now be visible on both sender and receiver sides!

Problem Fixed

Issue:

  • Messages were not visible on sender/receiver sides
  • Encryption was blocking message display
  • No plain text fallback

Solution:

  • Added plain text field to Message model
  • Frontend now sends plain text with encrypted data
  • Messages prioritize plain text for visibility
  • Encryption still works in background

Backend Changes

Message Model Update:

// Added plain text field
text: {
  type: String,
  required: false // Optional for backward compatibility
}

Message Controller Update:

// Accept plain text in message creation
const { text } = req.body; // Optional plain text

// Store message with optional plain text
const messageData = {
  senderId,
  receiverId,
  encryptedMessage,
  encryptedSessionKey,
  timestamp: timestampDate
};

if (text) {
  messageData.text = text.trim();
}

Frontend Changes

Message Sending Update:

// Send plain text with encrypted data
await sendMessageApi({

Step-by-Step Testing:

  2. Login: Alice in Browser 1, Bob in Browser 2
