🔐 End-to-End Encryption Test

This test verifies that messages can be encrypted by sender and decrypted by receiver.

🧪 Test Controls

📋 Test Results

🔍 What This Tests

📤 Sender Side

  • Generates random AES-256 key
  • Encrypts message with AES-GCM
  • Encrypts AES key with RSA-OAEP
  • Stores both encrypted parts

📨 Receiver Side

  • Decrypts AES key with RSA private key
  • Decrypts message with AES-GCM
  • Verifies message integrity
  • Displays original plaintext

🎯 Expected Results

  • ✅ Success: Original message matches decrypted message
  • 🔐 Security: Tampering is detected
  • 📱 Usability: Real app works end-to-end

🌐 How to Test Real App

  1. Open KMune App
  2. Login as user with encryption keys (use fix tool if needed)
  3. Send a message to another user
  4. Verify message appears and can be decrypted
  5. Refresh page - messages should persist
