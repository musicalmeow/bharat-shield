🧪 KMune Message Persistence Test

This test verifies that messages persist across page refreshes.

🔧 Test Controls

📨 Current Messages in Storage

📋 Test Instructions

  1. Test LocalStorage: Check if localStorage is available
  2. Simulate Message Send: Add test messages to storage
  3. Simulate Page Refresh: Load messages from storage (simulates browser refresh)

Expected Behavior:
✅ Messages should appear instantly when loading a chat
✅ Messages should persist after page refresh
