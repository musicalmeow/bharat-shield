🔧 Fix Existing Users - KMune

This tool generates and stores encryption keys for existing users so they can login properly.

📋 What this does:
1. Generates RSA-2048 key pair for existing user
2. Stores keys in browser localStorage
3. Allows user to login without re-registering
4. Preserves existing messages and user data

👥 Existing Users

🔐 Instructions

  1. Select a user from the list below
  2. Click "Generate Keys" to create encryption keys
  3. Go to main app and login normally
  4. User will now work with proper encryption

Note: This only affects your browser. Other devices still need proper key setup.
